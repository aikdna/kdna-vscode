# KDNA for VS Code

VS Code extension for creating, validating, previewing, and packaging KDNA domain cognition files.

## Features

- **Validate** — Real-time diagnostics as you edit KDNA JSON files
- **Preview** — Webview panel showing rendered domain structure
- **Pack/Unpack** — Create and extract `.kdna` container files
- **Create** — Scaffold new domains from templates
- **Diagnostics** — Banned term highlighting, ontology concept hovers, cross-file consistency checks

## Install

Search "KDNA" in the VS Code Marketplace, or run:

```
code --install-extension aikdna.kdna-vscode
```
